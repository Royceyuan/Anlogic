# MAIN-5D 主板状态补齐

基线：`d4e6bc9` 控制修复版。只增加状态输出、PC 显示和协议说明，不改变按键、预载、讲解、暂停、图片处理及转场控制逻辑，不读写 TF 素材。

## 实现

复用 HEARTBEAT 保留字节 7、14、15，长度仍为 16 字节；不增加包类型、按键计数或按键事件。新增独立高亮、SW4～1、拨码预载目标、完整图片缓存文物、可进入讲解文物、独立暂停、预载中和恢复中。完整字节定义见 [双板联调计划](MAIN5_双板控制分配与以太网联调计划_20260925.md)。

图片缓存编号来自现有讲解控制器的真实缓存完整性和后台缓存就绪标志；不能只根据 `cache_ready` 判断，因为后台覆盖旧细节时旧组可能已不完整。可进入讲解条件另核对图像、音频、字幕、拨码和应用状态，高亮仍须与该编号一致。

PC 状态面板识别扩展有效位，旧固件不显示伪造的文物 0。状态变化主动触发发送，同时保留 500 ms 周期及查询快照；允许合并短暂中间状态，副板不把它当作可靠事件日志。
