# 静音手动浏览：单板验收版

这是临时本地入口，不是副板控制分配的修改。只用主板、TF卡、显示屏和原音频输出即可验证；不需要电脑网卡或副板。正式产品入口与正式 bit 保留原有行为。

## 文件与边界

- 验收 bit SHA-256：`F498100E7E5A80288D4566781DFEA7839D3484E47E006DFBB4C0A671B2D74FA1`，634313字节。
- 正式 bit：`release/dual_fpga_museum_terminal_main_board.bit`，SHA-256仍为`14D503535CA033A01CE2F5AC5805E97FD7E3A994D0A3E8866D67419D75076A14`，本轮未覆盖。

- 全貌、细节1、细节2、细节3顺序与转场、自动模式时间轴、TF内容、以太网协议不变。
- 模式/图号经同一手动控制通路送入原讲解FSM；没有第二套讲解状态机。

## 操作（拨码代码按 SW3:SW2:SW1，1表示逻辑ON）

SW4保持0。`101`和`110`原本是无效文物代码，仅在此验收 bit 中作为模式操作；不会选中“文物5/6”。拨码完整代码经两级同步、约21 ms稳定判断后只触发一次。建议每次模式代码保持0.5秒，再拨回有效文物代码。

| 操作 | 验收版行为 |
|---|---|
| `101` | 总览就绪时启用静音手动模式；讲解中仅完整当前缓存可用且不在转场/恢复/应急时接受 |
| `110` | 退出静音手动模式；正在浏览时先回全貌，完成其转场后收拢回总览，不续播旧音频 |
| `000`～`100` | 原文物0～4素材预载选择；高亮与就绪素材匹配才允许KEY2进入 |
| KEY1 | 总览循环高亮；展示中1×/2×切换（与正式版相同） |
| KEY2 | 总览确认进入；正常讲解暂停/继续；静音手动展示中不冻结转场 |
| KEY3 | 静音手动展示中循环全貌→细节1→细节2→细节3→全貌；总览仍切换OSD，正常讲解仍切换波形 |
| KEY4 | 原应用恢复；取消手动状态，回有效总览并重新加载，不需断电 |

操作正在转场、恢复、应急时不会排队补发。若`101/110`被忽略，等忙状态结束，先拨到有效代码再重新拨模式代码；KEY3被忽略则等转场结束后重新按。不能只维持原模式代码期待反复触发。

### 推荐验收顺序

1. 烧录验收 bit，SW4=0，SW1～3选择有效文物，等五栏总览形成并完成预载。
2. 在总览拨`101`保持0.5秒，然后拨回目标文物代码。等待素材就绪，用KEY1使高亮与该文物一致，按KEY2。
3. 应平滑进入全貌，无讲解声音、无字幕、无波形。停留超过原音频长度也不自动切图或自动结束。
4. 每次转场完成后按KEY3，应依次展示细节1、细节2、细节3，再通过原菱形转场回全貌。无加载黑幕；KEY1仍可缩放。
5. 静音浏览时切有效拨码到另一文物，当前四图应继续完整可切；此模式有意固定当前四图，不允许背景覆写细节槽位。退出后才继续下一文物预载。
6. 拨`110`保持0.5秒，再拨回有效目标代码；应先回全貌，然后平滑收拢总览。等待转场及素材/音频/字幕准备完成，按KEY2，应从头开始正常有声讲解。
7. 再重复进入、切图、退出；在静音浏览中按KEY4，应回总览并恢复正常模式。KEY4之后需重新执行一次`101`进入，保持不变的`101`不自动重发。
8. 使用KEY4、SW4应急、普通有声讲解、正常KEY3波形控制做回归，确认原功能仍正常。

若总览尚未完整生成就拨`101`，本次操作不会接受；等总览就绪后重试。正常讲解期间已开始下一文物后台读取，或旧细节已被覆写时，也不强行进入手动模式；优先KEY4回总览后按推荐步骤进入。

## 可重复验证与构建

从`Anlogic/sim`运行：

```powershell
& D:\Modelsim\win64\vsim.exe -c -do run_local_manual_test.do
& D:\Modelsim\win64\vsim.exe -c -do run_remote_controls.do
& D:\Modelsim\win64\vsim.exe -c -do run_museum_manual.do
```

前两项分别覆盖临时入口启用/关闭、拨码去抖、图号分发/回绕、转场与缓存保护、退出/恢复及原远程控制。最后一项验证实际讲解FSM的静音、图序、退出与后台缓存行为。集成仿真存储为stub，不代表真实TF/HDMI上板验收。

从`Anlogic`根目录运行：

```powershell
Get-Content scripts/build_museum_local_manual_test.tcl | & D:\TD_6.2.1\bin\td_commands_prompt.exe
Get-Content scripts/build_museum_local_manual_test_bitgen.tcl | & D:\TD_6.2.1\bin\td_commands_prompt.exe
```

独立报告/数据库位于`_build_local_manual_test`；bitgen必须通过setup/hold检查，不能使用违例数据库生成验收bit。资源与最终时序见`docs/reports/local_manual_test_20261001.md`。本轮seed2最终setup为+0.239ns、hold为+0.024ns、TNS均0；DRC/bitgen复查完成。

这只能证明主板手动媒体流程。MBP1命令、ACK、副板SW3与四键映射、状态联动仍需副板完成适配后双板验收；不把单板通过写成双板通过。
