## 生产入口中的实际操作

以 `src/memory/museum_display_subsystem.v` 启用的 MAIN-5 控制分支为准，不使用历史未启用分支的按键定义。

| 控件 | 总览 | 讲解 |
|---|---|---|
| KEY1 | 按0→1→2→3→4→0循环高亮 | 1×/2×缩放，暂停时可用 |
| KEY2 | 素材就绪且与高亮匹配后确认进入 | 暂停/继续 |
| KEY3 | 显示/隐藏总览OSD | 显示/隐藏音频可视化 |
| KEY4 | 应用恢复 | 应用恢复并回总览 |
| SW1～SW3 | 选择预载文物 | 可选择下一件预载文物 |
| SW4 | 应急控制 | 应急控制 |

证据：`museum_media_core.v` 中总览控制器 `key_next` 接 `key_press_pulse[0]`，MAIN-5 的 `key_press_pulse[2]` 接总览OSD/讲解波形显示控制。本轮纠正HANDOFF旧描述，不改变上述接线。

当前“手动切图”入口为手动选择文物并确认展示，不是讲解内“上一张/下一张”。自动推进由实际音频帧进度与TF字幕包四个切换时间驱动，顺序保持全貌→细节1→细节2→细节3→最终全貌→总览。如果赛方要求讲解内直接上一张/下一张，再确认操作分配后实施，不擅自改键。

- 文件系统：FAT32。
- 31个必需文件全部存在：5张全貌、15张细节、5个WAV、5个SUB、1个名称文件。
- 20张图片文件头均为BM、24位、compression=0、像素偏移54；尺寸均在生产上限内。
- 五个音频文件头均为PCM16、双声道、48000 Hz，使用标准data块位置。
- 五个字幕包均为MSUB版本3，包长与条数匹配，头部音频总帧数与相应WAV一致。
- 名称包ONAM版本1、3072字节。
- 本轮检查的是文件集合、头部、长度及相关字段，不是全文件哈希验证，也不证明字幕语义与音频逐句完全对齐。

## 下一步实板操作与预期现象

使用现有产品bit，无需重新编译或烧录；保持SW4=0。

1. 将SW1～SW3选择为文物0，等待素材就绪；用KEY1使高亮匹配，KEY2确认。
2. 预期平滑进入全貌，图片按既有时间轴自动推进，音频播放结束后最终全貌停留约1.2秒，再收拢回总览。检查无非设计黑屏、闪烁、卡死；既有纯黑边转场不算异常。
3. 在细节阶段按KEY2暂停，检查音频和图片推进停止；再次按KEY2后从原进度继续。
4. 返回总览后选择另一文物，等待就绪并确认。预期展示所选文物，不误用上一件素材。
5. 对0～4全部完成一次讲解和手动选择验证，至少重复进入同一文物一次。
6. 在独立测试卡补640×480原生24位非压缩BMP实板显示，确认读取、适配、边界与颜色正常；未经授权不改当前E盘。

负责人确认上述实板结果后再标记P0第2项完成，随后开展P0第3项长时间混合操作与故障恢复测试。本轮没有新增讲解内手动切图模式。
