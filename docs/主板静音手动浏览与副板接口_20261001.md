# 主板静音手动浏览与副板接口增量

日期：2026-10-01。本轮只改主板；不拉取、不修改副板。正常讲解基线为 `79037ed` 恢复的 `a0a6832`，负责人已验证基线功能及双板通信正常。电脑有线网卡仍故障，本文测试不依赖电脑连接实板。

## 1. 行为及后续副板控制

对应赛题基础功能的手动切图和自动轮播：复用现有讲解控制器、缓存及转场，不新增图像槽位、不改TF媒体格式、图片顺序或正常音画字幕时间轴。

| 副板状态 | 后续副板实现要求 |
|---|---|
| SW3=0 | 正常讲解；原SW2:SW1四组预设、参数、方向键分配不变；参数每按一次1档，方向每次20规范化源像素 |
| SW3=1 | 静音手动浏览；KEY1全貌、KEY2细节1、KEY3细节2、KEY4细节3，覆盖SW2:SW1的按键分组 |
| SW4 | 保留副屏展陈/工程监视页面切换，不断网 |

主板KEY1～KEY4及SW1～SW4的物理分配不变，主板SW3仍是文物预载编号bit2，不是手动开关。

1. 在总览开启手动模式，仅设置模式，不自动进入。主板拨码选择预载文物，KEY1选择匹配高亮，KEY2进入；手动入口只要求图片缓存就绪，不要求WAV或字幕入口准备好。
2. 在正常讲解的稳定画面切入，保留当前图，停止旧音频并隐藏字幕和波形，清除暂停，避免暂停锁住手动转场。手动模式不自动推进或自然结束；主板KEY2不暂停手动转场，KEY1仍可缩放，KEY4仍可恢复。
3. 四键选择绝对图号，不发送“下一张”的增量命令。图片已缓存，无需每次再读TF。复用目标细节图原有转场；细节回全貌用已有菱形转场，总览首次进入仍用原展开，退出仍走全貌再收拢回总览。重复选择当前图不重新转场。
4. 手动期间暂停下一文物后台图片预载，保护当前四图；主板拨码变化仍是下一预载目标，退出后恢复原预载流程。当前展示文物不会随拨码变化。
5. 正常讲解的后台预载若已覆盖当前细节缓存，切入返回BUSY；正在读图或转场也不抢占事务。请先回总览并等待当前目标图片完整就绪，再开启并进入手动。建议先开启手动再按主板KEY2，避免这一边界。
6. 切回正常模式不续播旧音频：先回全貌再平滑收拢到总览；再次KEY2从头播放完整讲解。正常模式重复收到“正常”命令不打断讲解。KEY4/应急应用恢复清除手动模式；副板须根据实际回报重新同步，不能仅按自身SW3猜测。

## 2. MBP1兼容增量

网络地址、CRC、版本1帧头、序号/会话、ACK及旧命令均不变。控制主板HELLO：`01 01 01 01 00 05 00 04 00 00 03 FF`，build_id=`0x00050004`，capability bit9表示手动浏览。未声明bit9的旧固件不发新命令。

### 0x17 BROWSE_MODE_SET，副→主，4字节，ACK_REQ

| 业务偏移 | 值 |
|---:|---|
| 0 | 0正常、1静音手动 |
| 1～3 | 必须为0 |

成功仅表示模式请求接受，不是转场完成。应急、恢复、转场、讲解结束流程、缓存不安全返回4 BUSY；非法模式/保留字段返回5 INVALID_STATE；长度错误返回2。模式改变时立即停止旧音频，退出时不恢复旧时间轴。

### 0x18 BROWSE_IMAGE_SET，副→主，4字节，ACK_REQ

| 业务偏移 | 值 |
|---:|---|
| 0 | 当前实际展示文物0～4，取HEARTBEAT字节1，不能用预载拨码代替 |
| 1 | 逻辑图号0全貌、1细节1、2细节2、3细节3 |
| 2～3 | 必须为0 |

只在已进入手动浏览、缓存完整、没有转场时接受。未开启手动/未进入/文物不匹配/图号越界/保留字段非0返回5；转场、恢复或缓存忙返回4。全貌仍映射实际物理槽0或4；不要直接将逻辑0作为视口命令的物理槽位。

### 实际状态回报

- DISPLAY_STATUS（0x16）仍12字节：字节6 bit2=`manual_mode`，总览也可能为1；bit0在手动时回报0，普通模式恢复保存的波形开关；其余字段不变。
- HEARTBEAT字节3和PLAYBACK_STATE字节1新增值5=静音手动浏览。转场仍优先报告3、返回过程中报告4；总览报告0。字节2/PLAYBACK_STATE字节2仍为物理槽0～4，总览255。
- 音频帧在手动浏览为0，不是暂停在旧进度；副屏不得继续滚动音频进度或显示旧字幕。
- HEARTBEAT已有高亮、拨码目标、缓存、可进入、恢复状态扩展保留。手动模式“可进入”只要求图片就绪，与正常模式要求音频字幕不同。
- 主板OSD显示原名称、图阶段、源尺寸、倍率和画面参数，未新增字体或OSD内容。

## 3. 后续副板事务规则

保持一条未确认控制事务。模式/图号使用绝对值，丢ACK按同seq、同payload重传；不能把重传解释成下一张。ACK成功后等待新的实际状态：

- 开启：字节6 bit2=1；若已在讲解，心跳须非转场且为静音状态5。
- 选图：文物匹配，DISPLAY_STATUS阶段与HEARTBEAT一致，逻辑0匹配物理0或4，其余匹配1/2/3；心跳非转场。
- 关闭：bit2=0且心跳阶段255/停止0，使用请求发出至少100ms后收到的新心跳，避开逻辑停止到下一帧真正开始收拢之间的短窗口；转场时仍报告3，结束后才解锁。不以ACK0立即切回“可调参”页面。阶段字段是控制槽位，转场期间不代表整屏已显示目标图。

手动模式/切图事务的状态确认限时8秒，旧预设/调参/平移保留1.5秒。100ms未ACK重发，最多10次；保活和RX不阻塞。BUSY结束当前seq，不同seq重试需基于新快照：拨码模式意图可以在转场结束后重新发送，但不积压旧图号按键。长时间BUSY或缓存不完整提示“回总览后重试”，不得无限盲发。

启动、KEY4恢复或新会话后，先HELLO+查询状态，再比较SW3与主板实际模式决定是否发送新模式请求；旧待发图号丢弃。断线不猜测主板模式，不回放断线按键。副板手动图号键仍需已就绪且实际进入浏览，不能仅凭SW3=1发送。
