# 640×480、30fps离线视频候选

先验收此版画质，再决定是否继续提高源分辨率。该独立工程尚未替换正式博物馆版本；旧640×360、30fps无噪点版本见[上板基线](BOARD_PASS_30FPS.md)。

## 文件与使用

- 工程入口：`secondary_tf_video_480p.al`
- 候选bit：`experiments/tf_video/secondary_tf_video_640x480_30fps_guard8.bit`
- 配套素材：工作区`素材/离线视频_640x480_30fps/VIDEO0.BIN`
- 播放文件名仍为TF根目录`VIDEO0.BIN`，无须手动配置映射
- 显示器仍接副板HDMIB；不接电脑HDMI/播放器；KEY2暂停/继续，KEY1初始化

使用新bit必须配新素材，不能把旧360行文件改名当作480行文件。由SPI工程转入时，先JTAG烧录，再拔插TF卡，最后按KEY1；不烧Flash。若失败回报完整8位数码管及现象，错误页定义沿用PLAYBACK.md。

## 480行有效内容与画幅

| 项目 | 已通过基线 | 本候选 |
|---|---:|---:|
| 文件中的RGB565采样点 | 640×360 | 640×480 |
| 每帧有效像素 | 230400 | 307200（增加33.3%） |
| 像素数据/帧 | 460800字节 | 614400字节 |
| 扇区/帧 | 900 | 1200 |
| 视频帧率 | 30fps | 30fps |
| 纯视频载荷 | 13.824MB/s | 18.432MB/s |
| HDMI有效输出 | 1280×720 | 1280×720 |

从原1280×720影片重新采样480行，保留整个剑身视场，不用上下黑边将360行凑成480行。640×480是变形采样，样本宽高比4:3；FPGA横向2倍、纵向3:2放大后，恢复原片16:9比例。不是要求用户改变播放器映射，也不声称横向真实细节增加。若把原始采样直接按4:3正方形像素观看会显得压窄，应以板端16:9输出为准。

本地垂直映射为`source_y=floor(2*output_y/3)`，通过0、1、2三相计数器实现，不在像素路径放除法器；行释放随源行变化，不沿用旧版每两输出行释放。完整720p逐像素测试覆盖三个缓存基址和帧重启。

## 存储与稳定性边界

独立工程采用三帧，32位字地址0、153600、307200；每槽153600字，共1843200字节（约1.76MiB），未超8MiB。第三帧用于吸收TF/FAT访问抖动，不通过提高SD或SDRAM时钟获取余量；保留已通过版8个50MHz时钟的读写换向保护、逐扇区CRC、整帧写完成确认、帧边界交接及错误保帧。

原读卡连续16MiB实测约24.21MB/s，比18.432MB/s纯像素负载多约23.9%，但这不是完整文件/显示链路的保证。文件簇访问、刷新及总线换向仍有开销。三帧缓存不会弥补长期带宽不足；读取落后时保持完整帧，不能将发布累加器的30Hz当作实测平均帧率。

原四个720p图片槽加本视频三帧会超过8MiB，因此借用了独立工程中不运行的图片地址空间。接回正式博物馆工程时必须重新划分，不能同时保留四图片槽又直接叠加本布局。正式工程、release及Flash本轮不变。

854×480 RGB565在30fps下需24.5952MB/s，已超过当前24.21MB/s原始读卡实测，尚未计入文件与显示开销；并非只要SDRAM装得下便能稳定30fps。若后续评估该格式，需重新选择帧率/存储格式及处理帧尾扇区对齐，本轮不混入。

## 构建与验收

```powershell
./scripts/build_tf_video.ps1 -Height 480 -TestOnly
./scripts/build_tf_video.ps1 -Height 480
```

默认不指定Height仍是360行构建，分别使用`_build_tf_video`和`_build_tf_video_480p`。尺寸宏写在独立工程配置，构建脚本不通过add_define改写工程。原生SD接口、PLL和HDMI扫描时序不变。

仿真覆盖原有SD/FAT/帧交接回归，完整640×480到720p逐像素对比，真实614400字节帧跨128扇区碎片簇与循环，错尺寸拒绝，三槽缩比调度，以及真实原厂跨域FIFO下后台写帧与720p读取并发、换向保护和刷新等待。并发测试使用抽象SDRAM延迟，不冒充物理SDRAM电气模型。仿真、源哈希、时序/DRC均通过后才交付bit；通过这些门禁不等于新候选已经上板通过。

上板请观察至少完整循环一次（约82.37秒），检查剑身比例、细节、边缘噪点、撕裂/停顿及多次暂停/恢复。旧bit和旧素材备份保留，可成对回退。
