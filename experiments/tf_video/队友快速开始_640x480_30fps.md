# 640×480、30fps离线视频：队友快速开始

远程副板分支：`secondary-main5e`。本交付以已上板通过的`3c7f9fa`为RTL基线；不含未提交的960×540试验，也不含Anlogic3的音视频集成修改。它是独立离线播放工程，不是已经集成所有功能的博物馆版本。

## 拉取与直接播放

先安装Git LFS，再拉取：

```powershell
git clone -b secondary-main5e git@github.com:Royceyuan/Anlogic.git
cd Anlogic
git lfs pull
powershell -NoProfile -ExecutionPolicy Bypass -File tools/OfflineVideo/prepare_480p_demo.ps1
```

最后一条命令不需要Python，会解压并整文件校验已通过的素材，输出到工程根目录`_media_tf_demo/VIDEO0.BIN`。把该文件复制到FAT32 TF卡根目录；卡上若已有不同内容的VIDEO0.BIN，先备份，不要格式化卡。也可以用脚本的`-Destination`指定自己的空目录，脚本拒绝覆盖不同文件。

1. 打开独立工程`secondary_tf_video_480p.al`，不是`secondary_tf_video.al`，也不是默认的博物馆工程。
2. 使用TD/JTAG临时下载`experiments/tf_video/secondary_tf_video_640x480_30fps_guard8.bit`，不必重新综合，不烧Flash。
3. 下载后将TF卡拔出再插入，再按副板KEY1。正式博物馆用SPI，本工程用原生4位SD；仅重配FPGA不会给卡断电，卡残留SPI模式时可能显示F0910009。
4. 显示器连接副板HDMIB，不接电脑HDMI，也不需要PC播放器或串口。
5. 自动循环播放82.3667秒越王勾践剑样片；KEY2暂停/继续，KEY1重新初始化。其余本地按键与拨码不用于此独立验证。

TF根目录文件名必须为`VIDEO0.BIN`。压缩包本身不能直接放到TF上播放；MP4也不能直接播放。本工程读取MVID v1原始像素，不解码H.264。

## 使用自己的视频

仅重新转换素材需要Python 3；转换程序只用标准库，不用pip安装依赖。FFmpeg及配套DLL已在本副板仓库中，不依赖主板工程、Anlogic3或个人绝对路径。

```powershell
py -3 tools/OfflineVideo/convert_video.py --self-test
py -3 tools/OfflineVideo/convert_video.py --height 480 --fps 30 --input "自己的视频.mp4" --output "输出目录/VIDEO0.BIN"
py -3 tools/OfflineVideo/convert_video.py --check "输出目录/VIDEO0.BIN"
```

输入可以换成自己的片，输出仍须640×480、30fps、RGB565-BE、MVID v1。工具默认高度是360，**必须明确传`--height 480 --fps 30`**。工具拒绝覆盖已有输出。单文件须小于4GiB，30fps约每秒18.432MB，不宜直接用很长影片。

640×480采样经过横向2倍、纵向3:2映射，以1280×720输出并恢复原16:9视场；不是上下添加黑边凑成480行。三帧SDRAM缓存总计1843200字节，读写换向保护为8个50MHz时钟。

## 改RTL和复现构建

安装TD 6.2.1、Icarus Verilog后，在本仓库运行；工具路径不同则通过参数指定：

```powershell
./scripts/build_tf_video.ps1 -Height 480 -TestOnly
./scripts/build_tf_video.ps1 -Height 480
```

不要改成默认360行入口。成功基线资源：5054 LUT、3354寄存器、8 BRAM9K、0 DSP、2 PLL；seed8，setup +0.109ns、hold +0.023ns。位流已通过实板播放反馈；这里的30fps为文件及调度目标，并无仪器测得平均帧率或长时间压力测试数据。

此版本静音，暂不运行以太网控制、主板字幕、原图片轮播、说明页、应急或电脑HDMI输入。要尝试另一条集成路线，可从本检查点自行建分支；不要把此位流当作原博物馆全功能发布版。
