# 主板等效资源优化验证（2026-10-01）

基线：已推送的 `a0a6832`，包含全部主板交互、UDP/MBP1 控制、媒体及纯黑边细节图2→3转场。本轮不改变功能、TF 内容、协议、缓存容量、图片顺序或音画字幕时间轴。

## 最终保留的修改

仅修改 `src/storage/fat32_image_loader.v`：BMP 签名、DIB 长度、色平面数、位深和压缩方式只用于固定值判断，原先保存共112位。改为按14个对应字节累计格式匹配标志，每次接受新的根目录文件时重新置位；任一字节不匹配即拒绝本次格式。

宽、高、数据偏移、目录文件长度、读取字节数及像素坐标仍保留原有32位值和校验；没有截短输入头部来绕过超限检查。BMP/BIN、自适应/旧采样模式接口不变，未增加读图等待、RAM、DSP或视频流水线延迟。

## 未保留的尝试

- BMP 横坐标在自适应有效宽度范围内改为11位：1,844,040组合法宽度/列位置与基线逐拍相同，但完整构建种子1 setup为-1.093 ns；仅复核一次种子2仍为-3.600 ns。未发布，计数器恢复32位，构建种子恢复1。
- 接受文件长度范围内的读取字节计数改为23位：39组进位、扇区及长度上限测试和大图测试通过；完整构建setup +0.210 ns、hold +0.022 ns，但整机为16741 LUT、11255寄存器、9476 Slice，较基线增加4 LUT、39 Slice。因此撤回，不以少9位计数寄存器宣称资源收益。

最终恢复并使用第一项完整构建的配套布局布线数据库、面积及最终时序报告生成bit；它与保留的头部校验源码对应，不使用上述撤回尝试的网表。构建入口脚本保持原样。
