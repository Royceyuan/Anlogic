# MAIN-5D KEY4 缩放恢复修复

## 原因与范围

用户在 2× 讲解中按 KEY4 后，总览仍被放大，OSD 同时显示总览和 ZOOM2×。
`museum_media_core.v` 的应用恢复分支在消隐边界切换到总览缓存，但没有同步清除显示端 `display_zoom_2x` 和 `display_pan_x/y`。
控制端的倍率虽已复位，正常倍率切换仅在非总览时执行，因此无法纠正残留的显示倍率。

修复仅在原恢复分支同一帧边界清零这三个显示寄存器；复用原 FIFO/行缓存重启流程。
KEY4 和 SW4 应急共用该路径。未改通信协议、图片/音频/字幕时间轴、TF 文件、预设参数或按键定义。
已验收的 `hx4s20_main5d_status.bit` 保留；此次补丁需重新实板验收。

## 仿真

在现有 `sim/run_main5_remote.do` 中增加定向回归：暂停讲解，切换 2× 并远程平移，再按 KEY4；
检查总览缓存切换时倍率为 1×、偏移为零，遥测同步归零，恢复结束后多帧不回到旧视口。

- 修改前：`main5_key4_before.log` 报 `Fatal: KEY4 overview retained lecture zoom/pan`。
- 修改后：`main5_key4_after.log` 报 `PASS MAIN5 KEY4 restores 1x centered overview from paused 2x pan`。
- `run_main3_recovery.do`：读写收尾、SD 重新初始化、超时重试及重复 KEY4 隔离通过。
- `run_main4_emergency_recovery.do`：SW4 优先级、应急期间保持恢复、帧边界退出通过。
- `run_main5_local_controls.do`：KEY3 总览 OSD / 讲解波形切换通过。
- `run_museum_lecture_main2.do`：讲解状态机回归通过。

运行方法（仓库根目录 PowerShell）：

```powershell
cd sim
& D:\Modelsim\win64\vsim.exe -c -do run_main5_remote.do -l main5_key4_after.log
```

## 构建复现

复用已验收构建脚本，仅替换输出目录/文件名，固定种子 1、原始约束，不降频或放宽约束：

```powershell
Get-Content scripts/build_main5d_status.tcl | ForEach-Object { $_.Replace('_build_main5d_status','_build_main5d_key4') } | & D:\TD_6.2.1\bin\td_commands_prompt.exe | Tee-Object -FilePath main5d_key4_build.log
Get-Content scripts/build_main5d_status_bitgen.tcl | ForEach-Object { $_.Replace('_build_main5d_status','_build_main5d_key4').Replace('hx4s20_main5d_status.bit','hx4s20_main5d_key4.bit') } | & D:\TD_6.2.1\bin\td_commands_prompt.exe | Tee-Object -FilePath main5d_key4_bitgen.log
```

## 发布结果

- 新 bit：`release/hx4s20_main5d_key4.bit`。
- SHA-256：`421252E70F7757EB75226A7C01A94A093AA8A12F94CD56AE4D9E0C59D52BB43C`。
- 最终 setup +0.117 ns、hold +0.024 ns，TNS 均为 0。
- Slice 9405/9800（95.97%，上一版 9569）；LUT 16779（上一版 16845）；寄存器 11473（上一版 11495）。
- BRAM9K 43、BRAM32K 10、DSP 13，均与上一版相同。资源差异包含工具重新布局优化影响。
- DRC 无多驱动、无异常时序路径，布线冲突为 0，bitgen 成功。
- 仍有原有 PLL 推导命令过时、PLL 反馈路由及 SDRAM_CLK 本地布线警告；未据此宣称警告全清。
- 报告：`docs/reports/main5d_key4_area.rpt`、`main5d_key4_timing.rpt`、`main5d_key4_drc_bitgen.rpt`。

## 上板检查

1. 讲解进入 2×，按 KEY4：回到完整五栏总览，OSD 为 ZOOM1×，不再出现放大的局部总览。
2. 2× 平移后暂停，再按 KEY4：结果相同；预载完成后能够再次进入讲解。
3. 1× 平移后按 KEY4、转场中按 KEY4：应回到无偏移的完整总览。
4. 2× 时 SW4 进入/退出应急：回到正常总览，后续按键及以太网控制可用。
5. 连续重复上述操作，检查音频、字幕、拨码预载和讲解重入无退步。
