## 实际修改

1. **转场栏目位置**：用带符号可变系数乘法映射到一个 DSP，替代加法/取负串联。位置、裁剪和单周期几何延迟不变。
2. **OSD 字符坐标**：在已有 s0 流水级提前计算行坐标、列坐标及列内有效范围，断开区域选择后的长组合路径。OSD 仍为三周期。
3. **字幕 RAM**：字幕宽度提交时一并保存居中起点，避免每个像素重复串联计算；仅 MAIN-5 远程控制入口启用四个既有 BRAM 的原生输出寄存器，不增加 RAM 块数。RGB、HS/VS/DE、XY、位索引、bank、描边和渐变可见标志同步延迟一拍。旧入口的 `PIPE_RAM_OUTPUT` 默认为 0。
4. **颜色计算**：12 位有符号到 8 位无符号的限幅改为符号位/高位判断；饱和度系数在已有上一级寄存器处解码，颜色路径仍为三周期。
5. **转场控制阈值**：16/32/64/128 的比较改成等价高位判断，削短高扇出控制路径，不改状态机流程。

遵循最小改动原则，没有重写媒体状态机、删除字幕或缩减缓存，也没有进行随机种子搜索。

## 上板顺序与预期现象

1. 核对 SHA-256 后烧录本次 MAIN-5D bit，使用现有 TF 卡，不需重新生成素材。
2. 五件文物分别进入讲解；图片顺序、转场速度、裁剪、自适应、音频与字幕时间轴保持原样。尤其检查字幕描边、OSD 字符与波形没有横向错位、闪烁或残留。
3. 同一件文物连续讲解两次；中途 KEY4 返回后再次进入，再拨码预载其他文物，字幕应每次正常出现。
4. KEY1：总览循环高亮、讲解 1×/2×；KEY2：确认/暂停继续；KEY3：总览 OSD 显隐、讲解波形显隐；KEY4：应用恢复。总览不显示普通波形，暂停期间波形归零。
5. 讲解时拨 SW1～3 预载下一文物；切换 SW4 进入应急，红色波形随告警音变化；解除后正确返回。不要将 SW4 当作长按按键。
6. 后续 PC/副板 MBP1 联调中，远程预设、亮度/对比度/饱和度/色温及缩放视口平移应按既定协议生效，面板、字幕不受图片调色污染。

**旧 `tools/mbp1_pc_peer.py` 是 5B 诊断检查，硬编码预设命令返回 `UNSUPPORTED=3`。本次 5D 已启用远程控制，正常预设应接受，不能直接用旧脚本的该项断言判断本 bit 失败。** 本轮时序闭合不替代后续 MAIN-5D PC 与副板实测验收。

若有异常，记录文物编号、拨码、操作顺序、发生在总览/转场/讲解/暂停哪个阶段，并使用保留的 MAIN-5C bit 对照。当前不标记 MAIN-5D BOARD PASS。
