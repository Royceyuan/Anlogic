# 素材工具验证记录 — 2026-10-03

范围仅为电脑端工具及媒体生成脚本；未修改主副板 RTL、bit、真实素材或 TF 卡。保留工作区原有 RTL 修改和 BAT 删除，本次不提交它们。

## 已通过

- `test_media_formats.py`：UTF-8 BOM、UTF-16 LE/BE、UTF-32 BOM、GB18030，点号/逗号毫秒、空白行、多行文本、常见样式标签；无效时间在非校准模式拒绝。
- WAV：PCM8、PCM24、float32、IMA ADPCM、mu-law，单声道/不同采样率经 FFmpeg 转为规范 PCM16/48kHz/双声道；假 WAV 拒绝。
- 六文件素材输入、不要求切图脚本、自动五等分，旧脚本仍兼容；字幕句切点使用校准后的时间；过期 SRT 校验值和非法切点拒绝，失败无半成品包。
- GUI：五件文物标签页、每件四个字幕句选择、后台生成、处理期间禁止重复生成、完成后按钮恢复。帮助页内置、只读、可滚动、独立关闭。
- `test_packager_exe.py --offline`：把 EXE、模型、运行组件、FFmpeg 复制到临时目录，清除 PYTHONPATH/PYTHONHOME，PATH 只保留 System32；完整生成五组音频、校准 SRT 和 31 个 TF 文件。用真实越王勾践剑音频构造五组不同编号素材，原 SRT 时间全部改为零且保存 UTF-16；仍保留全部文字和顺序，四个切点与校准 SRT 及 SUB 头一致。校准组件禁止建立网络连接。
- 基础 EXE 不带运行组件/模型时，规范 WAV 仍可独立生成 31 文件，结果与源码逐文件 SHA-256 相同。PE 为 GUI 子系统，音频转换及校准子进程以 CREATE_NO_WINDOW 运行。
- 真实素材正向回归：文物0、2、3、4，共25/30/31/31句，校准时间有效、原文和顺序不变。CPU 源码组件一次批处理约28.3秒，打包组件约26.4秒；仅说明本机耗时，不是其他电脑的保证。部分短字/低置信度提示需试听，未宣称逐句绝对准确。
- 负向回归：本地四羊方尊源 WAV 约32.241秒（源采样率40kHz），源 SRT 到76.1秒。独立识别仅到“造型雄……”附近，校准在第15句拒绝未定位内容，不补造缺失音频、不改原字幕、不回退为比例压缩。该结论仅针对素材目录中的这个 WAV，不代表当前板上 TF 音频有问题。

## 仍需用户内容验收

模型校准可能有局部偏差。校准后试听每句起止时间及四个切点，再把 TF_CARD 文件复制到卡上上板验收；软件格式验证不能证明图片语义、音频内容或整个板端时序绝对正确。

当前素材目录的四羊方尊需提供包含完整讲解的音频，或使 SRT 文字确实对应已有音频；工具不会擅自删掉后半字幕来掩盖源内容缺失。
