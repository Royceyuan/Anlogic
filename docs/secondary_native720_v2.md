# 副屏原生 720p v2 候选版（2026-09-25）

## 本次修正

- 进入讲解时记住当时屏幕上**实际显示**的文物；KEY3 返回这张文物的轮播画面。即使 SD 卡仍在读另一张简介，只要返回文物已在 SDRAM，显示切换不等待读卡结束。
- 讲解页上修改 SW1～SW3，继续在后台预缓存新选文物的简介。新简介读完后仍保持原讲解画面，直到 KEY2 确认才切换。双简介缓冲选择避开当前显示页和要返回的文物图。
- 第一张文物图加载后优先预载逃生图。SW4 请求紧急模式时，在逃生图尚未就绪的情况下保持现有画面；逃生图就绪后直接切换，不显示短暂的 `EMERGENCY / MEDIA WAIT` 占位页。解除紧急模式后直接切回原讲解页或轮播页。
- SW1～SW3 为 5～7 时不误缓存 0 号简介。旧的非流式副屏配置维持原有选图行为。

图片资源沿用 `assets/secondary_exhibit_720p_tf/IMAGE0.BMP`～`IMAGEA.BMP`，均为 1280×720。没有生成或替换图片，也不需要修改已经写好这 11 张图的 SD 卡。

## 操作和预期

1. SRAM 下载 `release/hx4s20_secondary_native720_v2.bit`，数码管正常为 `8008`。上电首次读卡仍需等待首图；五张文物图顺序轮播。
2. SW1～SW3 选 0～4，等待简介预缓存完成后按 KEY2。正在读下一张轮播文物图时，已缓存的简介仍可切入。讲解中修改拨码会缓存新简介，画面保持原讲解页；再按 KEY2 才切新简介。
3. 按 KEY3 返回进入讲解前显示的文物图，随后继续轮播。普通图之间原有转场仍存在，因此切换需要转场帧，但不应重新读取 0 号图。
4. SW4 拨到紧急位置直接显示已预载的逃生图；拨回后恢复原画面。若开机时逃生图还没预载完，先保持当前图，完成后再显示逃生图。

本地预览还没有接入主板以太网命令；等待或错误占位页若出现 `MAIN LINK LOST`，表示当前链路未连接。正常图片页不应有这条底栏。
