# 主板资源优化验证（2026-09-30）

基线：`c6179ff`，包含左上角 480×60 OSD 和完整中文点阵。工具：TD 6.2.168116，布局种子 1，原有时序约束。

## 保留的修改

`mbp1_fixed_udp.v` 将仅用于固定值比较的 IP、端口、EtherType、ARP 操作码及协议头字段改为逐字节匹配标志。MAC 地址、长度、负载缓存、发送状态机和对外接口保持不变。固定地址仍为主板 192.168.10.1:5000、对端 192.168.10.2:5000。

未保留调参流水线位宽缩窄、图片写地址加法共享两项尝试：整机实现未获得资源收益。图片、字幕、音频、转场、OSD、按键和恢复逻辑与基线一致。

## 最终布局布线报告

| 项目 | 基线 | 本版 | 变化 |
|---|---:|---:|---:|
| LUT / 19600 | 16735（85.38%） | 16748（85.45%） | +13 |
| 寄存器 / 19600 | 11470（58.52%） | 11331（57.81%） | -139 |
| Slice / 9800 | 9434（96.27%） | 9433（96.26%） | -1 |
| BRAM9K / 64 | 43 | 43 | 0 |
| BRAM32K / 16 | 10 | 10 | 0 |
| DSP / 29 | 13 | 13 | 0 |
| Setup WNS | +0.253 ns | +0.225 ns | 无违例 |
| Hold WNS | +0.022 ns | +0.023 ns | 无违例 |

本版 setup/hold TNS 均为 0。收益主要为寄存器减少，不能视为已经解决 Slice 占用偏高的问题。DRC 仍报告原有 SDRAM 输出时钟使用局部布线的警告；无多驱动或异常时序路径。
